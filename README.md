# PROJECT HEART (가제)

귀엽고 가벼운 2D 대전격투게임. 지금은 **2단계 시제품(필살기 버전)** 입니다. 캐릭터는 아직 임시 네모 그림입니다.

## 해 보기

- 브라우저에서 `index.html`을 서버로 열면 됩니다: `node serve.mjs` → http://localhost:5173
- 스마트폰에서는 화면 터치 조작(왼쪽 조이스틱 + 버튼 4개, 커맨드는 조이스틱을 돌려서)이 자동으로 나옵니다. 가로로 돌리면 더 크게 보입니다.

## 조작 (키보드)

| | 이동 | 약펀치 | 강펀치 | 약킥 | 강킥 |
|---|---|---|---|---|---|
| 1P 모모 | W A S D | F | G | V | B |
| 2P 루루 | 방향키 | K | L | , | . |

필살기 = 커맨드 + P/K (약 버튼 = 1히트·짧게, 강 버튼 = 다단히트·길게)
- ↓↘→ + P 장풍 · →↓↘ + P 승룡권(무적) · ↓↙← + K 회오리킥 · ↓↘→↓↘→ + P 초필살기(10히트)
- 잡기 = 아주 가까이서 강펀치 (뒤+강펀치는 뒤로 던지기)

`H` 판정 박스 보기 · `Esc` 일시정지 · 게임패드 2개 지원

## 구조

| 파일 | 역할 |
|---|---|
| `src/data.js` | **모든 수치** (속도, 기술 프레임, 대미지). 손맛 조정은 여기서 |
| `src/fighter.js` | 캐릭터 동작 (이동, 공격, 가드, 피격) |
| `src/game.js` | 라운드 진행, 타격 판정, 모드 |
| `src/render.js` | 화면 그리기 (임시 네모 캐릭터) |
| `src/input.js` · `src/touch.js` | 키보드·게임패드·터치 입력 |
| `src/cpu.js` | 컴퓨터 상대 |
| `src/movelist.js` | 기술표 화면 (data.js에서 자동 생성) |
| `src/sound.js` | 임시 효과음 (합성음) |

## 진행 단계

1. ✅ 네모끼리 싸우기 (이동, 기본기 12개, 가드, 콤보, 라운드)
2. ✅ 커맨드 필살기(장풍·승룡권·회오리킥 약/강 + 초필살기), 잡기, 대시, 게이지, 캔슬 콤보
3. ⬜ 타격감 연출 강화
4. ⬜ 도트 그림
5. ⬜ 타이틀·캐릭터 선택·배경·음악
6. ⬜ CPU 강화
7. ⬜ 밸런스 조정
